## Featured Projects

### 🔴 Azure Honeypot & Microsoft Sentinel Detection Pipeline
**Status: Completed** | [GitHub Repository](https://github.com/nyakioGithendu/azure-honeypot-sentinel)

Deployed an internet-exposed Windows 10 honeypot in Azure and built an end-to-end SIEM detection pipeline using Log Analytics, Microsoft Sentinel, and KQL. Captured genuine external brute-force activity within hours, enriched logs via geo-IP Watchlist lookups, and correlated findings with VirusTotal (5,400+ abuse reports) and AbuseIPDB. Final deliverable: interactive Sentinel Workbook visualizing attack origins on a world map.
